# Инвестиционный навигатор

Веб-платформа для подбора мер государственной поддержки субъектов малого и среднего предпринимательства (МСП).

Система анализирует параметры проекта и помогает предпринимателю находить подходящие меры поддержки с учётом региона, формы деятельности, стадии проекта, раздела ОКВЭД и целей бизнеса.

## Возможности

- **Подбор мер поддержки** — оценка соответствия мер параметрам проекта.
- **Персональные рекомендации** — отображение процента соответствия, причин подбора и недостающих условий.
- **Каталог мер** — просмотр и поиск доступных мер государственной поддержки.
- **Регистрация и авторизация** — создание учётной записи и вход в систему.
- **Профиль предпринимателя** — сохранение и редактирование данных проекта.
- **Управление заявками** — отправка заявок на меры поддержки и просмотр своих заявок.

## Алгоритм подбора

Для оценки соответствия проекта условиям мер поддержки используется балльная модель.

Алгоритм учитывает:
- цель проекта;
- форму деятельности;
- стадию проекта;
- раздел ОКВЭД;
- регион реализации проекта;
- срок действия меры поддержки.

Начальное значение составляет 40 баллов. За совпадение с целью проекта начисляется 30 баллов, за соответствие каждому из четырёх дополнительных параметров — по 10 баллов.

Итоговая оценка ограничивается 100 баллами. При этом отдельно проверяются обязательные условия: если параметр не соответствует требованиям меры или срок её действия истёк, мера не считается подходящей.

Результат подбора содержит оценку соответствия, причины рекомендации и список условий, которым проект пока не соответствует.

## API

| Метод | Endpoint | Назначение |
|---|---|---|
| GET | `/api/meta` | Получение справочников |
| GET | `/api/measures` | Получение каталога мер |
| POST | `/api/recommend` | Подбор мер поддержки |
| POST | `/api/auth/register` | Регистрация |
| POST | `/api/auth/login` | Авторизация |
| GET | `/api/profile` | Получение профиля |
| PUT | `/api/profile` | Обновление профиля |
| POST | `/api/applications` | Отправка заявки |
| GET | `/api/applications` | Получение заявок пользователя |

Документация API после запуска backend доступна по адресу `http://localhost:8000/docs`.

## Запуск проекта

### Требования

- Python 3.12+
- Node.js 22.18+
- PostgreSQL

### 1. Клонирование репозитория

```bash
git clone https://github.com/Wafrr/invest-navigator.git
cd invest-navigator
```

### 2. Настройка базы данных

Создайте базу данных PostgreSQL с именем `invest_navigator`, если она ещё не создана:

```bash
createdb invest_navigator
```

По умолчанию backend использует следующие параметры подключения:

```text
postgresql+psycopg2://postgres:postgres@localhost/invest_navigator
```

Если ваши настройки PostgreSQL отличаются, задайте переменную окружения `DATABASE_URL` со своими параметрами подключения.

### 3. Запуск backend

```bash
cd backend

python3 -m venv .venv
source .venv/bin/activate

pip install -r requirements.txt

uvicorn main:app --reload
```

Backend будет доступен по адресу `http://localhost:8000`.

При первом запуске создаются таблицы базы данных и добавляются начальные данные.

### 4. Запуск frontend

Откройте второй терминал:

```bash
cd invest-navigator/frontend

npm install
npm run dev
```

Frontend будет доступен по адресу, указанному Vite в терминале (обычно `http://localhost:5173`).
